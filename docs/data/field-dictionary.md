# 字段字典（schema_version 1）

运行数据位于`shared/data/`，由服务端`internal/gamedata`加载并交叉校验。所有文件`status`必须为`test`：当前只有测试参数，没有正式数值。

## 通用约定

| 约定 | 规则 |
|---|---|
| `schema_version` | 整数；服务端只接受当前版本（1），不匹配直接拒绝启动/加载 |
| `status` | `test`；出现`final`前须有对应的验收证据 |
| ID | 稳定字符串；物品原型ID目前沿用策划中文名或`TEST-*`编号，实例物品另有唯一实例ID（M1） |
| 货币 | 整数最小单位，任何地方不使用浮点 |
| 重量 | `weight_centi`，1/100单位整数；负重上限`(80+有效臂力)×100` |
| 属性/进度 | `growth.Centi`，1/100定点整数；结算步长0.1=10 |
| 时间 | 秒；经济池按“运行小时”，滚动额度按“墙钟小时” |
| 比例 | `*_centi`表示百分数整数（50=50%） |

## 文件

| 文件 | 来源 | 维护方式 | 内容 |
|---|---|---|---|
| `items.json` | 基线§3.5、§1.4 | 人工 | 物品类别、堆叠上限（材料100/消耗20/装备1/银钱10000）、单位重量 |
| `recipes.json` | `equipment_ledger_v41.json` | 生成 | 制造/维修/回收配方、最大耐久、每次维修最大耐久损失、废料当量 |
| `economy.json` | `economy_v44.json` | 生成 | NPC材料价、订单报酬、预算池（初始/上限/每小时补充）、账号24小时滚动额度、每账号每节点200格 |
| `moves.json` | 招式样表附录 | 生成 | 剑拳招式的伤害、内力/体力、前摇/有效/后摇、冷却；几何范围待M4补 |
| `routes.json` | `transmission_routes_v39.json` | 生成 | 12个授业节点、前置熟练度、客授与跨体系权限 |
| `world.json` | 闭环§二、基线§0.1/§1/§3 | 人工 | 六区块与连线、区域权限、角色数、背包与负重、尸体、物流班次、战斗计时、成长与生活技能参数、价格调整窗口 |
| `map.json` | 闭环§二、招式样表§一 | 人工 | 灰盒地图几何（米）：区块矩形、道路折线与宽度、风险区、障碍物、出生点；步行速度 4 米/秒、tick 20Hz、快照 10Hz、视野 80 米、每秒移动请求上限。加载时与 `world.json` 交叉校验：区块一致、每条连线都有道路、风险捷径必须标为风险区 |

## 修改流程

1. 改`docs/design/`中的源JSON，或改人工维护文件并注明来源。
2. 运行`python3 scripts/export_data.py`。
3. 运行`./scripts/check.sh`：服务端对照测试会与Python演算的黄金结果比较，数值变化导致的不一致必须显式处理。
