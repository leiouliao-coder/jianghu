## 发现的问题

1. **客户端测试可能静默通过**：GDScript运行时出错会中断测试，但Godot退出码仍是0，之前CI只看退出码。新增`scripts/run_client_tests.sh`，把退出码非0、输出含SCRIPT ERROR、没有打印PASS都判为失败，CI已改用它；并用一个故意写错的节点路径验证过它能抓到这种情况。
2. 角色死亡或出招时请求移动，服务端原先回“内部错误”，现已明确回`busy`。
3. 一个旧测试凭空创建遗物，被新的数据库约束挡下；现在遗物只能由死亡产生。
4. 一个测试“假通过”：角色死在风险区，离开本该延迟，测试却在角色并未离开时就重新进入了。已改为等真正离开。
5. 右键选中怪物后，目标框要等下一次快照才出现；现已立即刷新。
6. 普攻未收招时按Q会被拒绝、提示“正忙”；已加0.6秒招式缓冲。

## 已知问题与未验证

- **字体缺字**：提示文字中的“敌”显示为方框。客户端依赖系统自带的中文字体，Windows和安卓上可能更严重。建议内置开源中文字体（思源黑体 / Noto Sans SC，OFL许可）。
- 两人贴身时头顶名字会重叠，等正式模型到了按模型高度调整。
- 招式范围预览（基线§3.1“按住预览松开释放”）、Tab切换目标、A+左键攻击移动，尚未实现。
- 武器零耐久或未装备武器时禁用持械招式，要等M6装备系统实现。
- 气血、内力、体力不随离线保存（重新进入时为满值）；死亡状态会保存。
- 怪物不掉落，要等后续物品与掉落表。
- 维护停机时遗物期限顺延（基线§4.2），在M5与物流期限一起实现。
