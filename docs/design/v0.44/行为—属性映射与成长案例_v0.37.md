# 行为—属性映射与成长结算案例（v0.38已同意测试方案）

## 状态与使用范围
用户已确认成长结构，并于v0.38同意本映射与18例先作测试方案；初值各20、普通单项100、总额300、被动减少最低10、属性步长0.1、每门武学熟练度0—1000均为测试参数，不是最终平衡。根骨、定力等映射采用已同意的方向，具体哪一次行为有效、给予多少训练进度、成长耗时仍待原型验证。

以下执行口径已由C209—C210确认：只在新有效实践时尝试属性结算，切换提高／锁定／减少按钮不即时发点；每次整步0.1原子结算，来源不足整步时跳过，不能跨多个不足0.1的来源拼扣；进度以归一化token演示，满1表示具备一次增长0.1的资格，不代表做一次动作必涨0.1。不实现未确定的成长概率、时长、掉落概率或最终派生公式。

## 行为—属性映射表
| 行为 | 对应属性方向 | 技能判定独立性与有效性候选 |
|---|---|---|
| 砍伐树木 | 臂力，已确认方向 | 伐木技能独立；目标合法、完成实际劳动，难度适宜条件待测 |
| 打铁成形 | 臂力，已确认方向 | 锻造独立；完成有意义工序，不以取消重开刷进度 |
| 力量型武学训练 | 臂力，已同意方向 | 对应武学独立；适宜负荷的训练可有效，不要求击杀 |
| 基础体能 | 根骨，已同意方向 | 完成适宜强度训练；不以挨打、跳崖、濒死为刷点来源 |
| 桩功训练 | 根骨，已同意方向 | 有效姿势、时间或训练目标的识别方式待测 |
| 轻功训练 | 身法，已确认方向 | 轻功熟练度独立；纯空放不保证有效 |
| 步法演练 | 身法，已同意方向 | 路径、节奏或训练要求候选，不预设点击次数奖励 |
| 有效闪避 | 身法，已同意方向 | 实际避开有效威胁；风险和重复互刷识别待测 |
| 阅读研习 | 悟性，已确认方向 | 读懂适合内容；不是同一页无限开关刷点 |
| 解读相关内容 | 悟性，已同意方向 | 题材和难度匹配待定；不成为所有技能的成长倍率 |
| 调息与稳定运功 | 定力，已同意方向 | 对应内功另判；需要专注的有效完成条件待测 |
| 专注工艺训练 | 定力，已同意方向 | 对应生活技能另判；哪些工序满足条件待逐项定义 |

本表不是“一个行为只能影响一项”的最终规则，也未确认复合行为的分配权重。同一次行为是否产生多属性进度，须之后按行为细分，不能重复发放无上限收益。每项均须有可单人完成路径。生活技能独立总预算与单项上限继续生效；本案例不新增生活技能提高／锁定／减少按钮。

## 属性、技能与特性的结算顺序
1. 读取永久属性、个人单项和总上限、增减状态、来源优先级。
2. 新有效实践分别判定技能熟练度与属性训练资格；角色离线不发生实践。
3. 属性进度最高保留1份增长资格。目标锁定、进度不足、单项已满或无可减来源时，属性不变，保留至多1份；不阻止满足条件的技能独立增长。
4. 目标设置提高且已满1份资格时，先检查单项上限；预算未满可增长，预算满则按优先级找允许减少且能完整扣0.1、不低于10的来源。找不到则不扣不加。
5. 同一事务中扣来源、加目标，成功才消耗1份进度。重新计算当前属性依赖特性，不删除已学内容或熟练度。

技能还要满足它自己的条件、上限和生活预算。某项技能已满，不自动禁止该劳动训练属性。武学、内功、轻功各自记录0—1000熟练度，不设置全部武学熟练度总预算；学习资格和高深掌握条件仍独立存在。

### 案例中的关键边界
- **02**：臂力设提高、悟性设减少；其余锁定。满300时臂力+0.1、悟性−0.1，总额不变。
- **03**：五属性锁定，锻造满足独立条件且未达自己的上限／预算，因此锻造10→10.1；臂力不变。技能+0.1只是假定本次技能判定结果，不是统一收益。
- **04**：目标臂力提高、其余全部锁定，没有合法来源，保留1份进度。若五项全锁亦不能属性增长，不以“总有一个提高”作为必要设定。
- **05a—05b**：假定一个特性要求“当前悟性≥50”。悟性降49.9时特性停用；已学武学及熟练度600均保留。不影响无此门槛的内容，不乘算全部伤害和成长。下一次有效实践合法转移后，悟性回50，特性恢复。阈值50是本轮示例，不是所有武学的统一门槛。
- **06**：臂力已100，即使悟性可以减，也不扣悟性；先查单项避免“扣了却没加”。
- **07a—07b**：材料只把臂力上限100→105，当前仍100、总300。不直接送5点。之后练到100.1仍须依法从悟性扣0.1。105已获准用于本案例测试；正式材料、突破幅度、次数及终局边界未定。
- **08a—08c**：另一种材料只把总上限300→305，当前仍300、单项仍100。继续练已100的臂力不涨；练尚80的根骨可到80.1，总额300.1，无需扣别项。305已获准用于本案例测试；正式材料、突破幅度、次数及终局边界未定，不意味着每份材料固定加5。
- **09a—09b**：来源优先悟性再定力。悟性已最低10，回退定力扣0.1。另一例两来源各10.05，均不足完整一步，整笔失败，不能各扣0.05凑数；此整步不拼扣规则已由C210确认，0.1仍为测试步长。
- **10**：永久臂力90，示例装备临时+10可显示有效100，永久总额仍300。不能因此多练永久点或增加永久上限；临时有效值与派生收益封顶公式另定，不声称已验证装备平衡。
- **11—13**：8份新进度也不能囤成8次洗点，受阻只保留1；离线不增加，切按钮不自动兑现。之后仍须新有效实践触发。新有效实践触发与按钮不立即兑现已由C209确认，进度封顶沿用既定结构。

## 执行与证据范围
运行：`python3 "docs/design/v0.44/verify_growth_v37.py" --input "docs/design/v0.44/growth_cases_v37.json"`。
脚本使用Decimal，逐例输出前后五属性与总额、属性状态、上限、进度、独立技能前后值、悟性特性状态及断言。18个独立子例通过；它仅核验本表算术和已同意的测试结算口径，不是游戏服务器、成长速度、战斗、反作弊或平衡验证。

仍待细化：各行为有效阈值与复合映射；70／90之后的放缓曲线；武学熟练度收益曲线和高深掌握条件；装备临时有效值限制；材料来源及有限突破边界。本轮不引入离线收益、万能潜能点、生活技能新状态系统，也不强制组队或PVP成长。

补充证据边界：不模拟真实天材地宝物品扣除、获取概率或使用次数；各例为独立输入夹具。09b的10.05等值是专门构造的精度边界输入，不表示普通0.1步长自然产生0.05。
