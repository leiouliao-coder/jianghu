# 首个可玩闭环：地图、节点、NPC、任务与验收方案（v0.43确认）

状态：v0.43 用户已同意首个可玩闭环按本方案确定；名称和具体数值为测试参数，16项作为待执行验收清单。不是正式首发定案，不表示已完成开发或通过游戏验收。

## 一、这次原型要证明什么

目标不是先铺大世界，而是在一个持续运行的小地区里证明：只有一名真实玩家，也能通过同账号多个角色完成战斗成长、生活生产、地域仓储、运输、交易服务与装备退出；多人加入后，可以协作和竞争，但不会破坏这条基础路径。正式世界不常规清档的原则不变；原型测试环境是否重置、怎样保留测试记录另行确定。

原型先复用剑拳招式测试方案、两派加散人传承测试路线及一把剑、一件布护具的物料账。不把所有传承名称都展开成完整新武学资产，不据此承诺最终规模、工期或服务器容量。

## 二、六区块连通地图，只有两个物流节点

地图先做连通拓扑，不承诺平方公里、移动耗时或服务器分区数量。

| 区块 | 建议内容 | 与闭环的关系 |
|---|---|---|
| A 河湾镇 | 安全服务区、物流节点 A、矿冶锻设施 | 建角引导、仓储寄售、兵器加工与基础复活 |
| B 石桥驿 | 安全服务区、物流节点 B、纤织裁缝设施 | 目的地交付、布护具生产、基础复活 |
| C 矿区 | 普通野外、矿点、适宜 PVE 威胁 | 采矿、战斗成长与原料运输 |
| D 纤维采集区 | 普通野外、纤维点、采集教学 | 裁缝链原料与普通成长 |
| E 教学驻地 | 听雨门与磐石堂两处驻地 | 剑拳教学、门派事务和个人考核，不新增仓库节点 |
| F 古道挑战区 | 普通单人挑战部分、可选高风险支路 | 高阶个人考验、公共事件与风险运输；必要授业 NPC 位于普通部分 |

建议普通连线为 A—C、A—E、A—B、B—D、B—E、B—F，F 内另设清晰边界的风险捷径，可连回 A 侧。A—B 必须有可独行的普通运输路线；捷径只能提供时间或经营上的选择，不独占正常材料、传承和必要进阶。

本闭环采用的区域权限规则：A、B 服务区禁止攻击；C、D、普通道路与教学范围禁止非自愿 PVP，但保留已告知的 PVE 危险；风险子区明确提示后自愿进入。普通野外不因此变成“登出安全区”。进入安全区不清除既有战斗，战斗优先于秒退；只有非战状态符合安全区正常登出条件时才立即离场。

所有地区死亡仍掉落实际随身实物，任何人可立即拾取，拾取成功转属；本地安全点复活，尸体到期销毁剩余物，30 分钟是既定测试参数。普通区也不额外增加保险或自动返还。

## 三、两节点怎样产生真实物流

两节点都提供基础仓储、本地交付、市场和托管服务，可由同一服务 NPC 的不同界面承接。沿用账号每节点 200 格等已同意测试参数，全局可查商品，实物在当地交付。同账号角色只共享同节点空间，不能通过切角跨节点搬货。

A 先突出矿石—冶炼—锻造，B 先突出纤维—纺织—裁缝；这只是原型布置重点，不规定设施永久独占。两地均能得到可靠的基础补给。高级制造和高级维修由合格生活角色完成，NPC 不代做高级成品。

教学订单安排一次 A 到 B 的金属材料调运，再安排一次 B 到 A 的纺织材料调运；货物必须真实合法入仓，运输调度锁定原物。先验证有班次、有运力限制的 NPC 基础承运，以及玩家自行押送；玩家承运合同同时保留可测入口，但单人主线不依赖其他人接单。普通托运不默认保赔，担保款与货损责任分别结算，不能复制补货。

接单、成交等新交付承诺前预留容量，待领转仓不重复计数；领取到背包检查负重。满仓不吞物、不直接判承运人违约；到期进入本地逾期保管，不拍卖销毁。收货人离线不暂停运输，系统验收和在线领取分开。

## 四、NPC 按职能安排，不先堆人物数量

| 地点 | 原型服务职能 | 实现边界 |
|---|---|---|
| A、B | 仓储寄售与托管管理员 | 可共用人物模型，节点库存与权限独立 |
| A、B | 镖务调度、合同查询与到货领取 | 有班次运力，记录真实交付，不无限瞬送 |
| A、B | 基础补给与有限采购订单 | 预算持续补充但有额度，不无限固定价买入 |
| A、B | 安全复活、资源恢复与引导 | 不附赠高级装备，不以复活搬货 |
| A | 矿冶锻教学与基础维修 | 只在规定基础档提供服务，高级部分交给生活角色 |
| B | 采纤纺织裁缝教学与基础维修 | 同上，维修归相应专业 |
| E | 两派入门、进阶、高深、秘传授业 | 按课程与身份逐项检查 |
| A、B、F | 散人分段授业和个人考核 | 稳定可达，不依赖限量奇遇或玩家师父 |

复用现传承路线的 12 个授业身份：听雨门顾砚、叶听澜、沈照、闻素；磐石堂陆平、秦岳、孟嶂、韩峙；散人陶行舟、杜遥、柳归、温渡。可先用占位外形与对话验证全部权限节点，但不得因为共用模型而合并师承、信任或授业资格。上述名称继续为测试方案，不表示 NPC 已经存在。

## 五、主任务链与并行分支

主链按可重复检查的阶段推进：

1. **落脚与识规**：建角，在 A 完成移动、负重、死亡和节点仓储教学；领取有限基础补给。
2. **试艺与择路**：体验剑拳基础招式，选择一派或散人入口；记录授业资格，而非选中就自动学全套。
3. **两条原料线**：到 C、D 完成适宜采集；分别加工，技能与属性独立判定，锁定属性不阻止合法技能成长。
4. **完成一剑一衣**：资格、知识、设施、材料齐备后制造，实物扣减和成品生成一次结算；不同角色可通过本地共享仓库接续。
5. **送达另一端**：将合法入仓原料委托跨节点运输，预留容量；一次收货人离线到货，再上线当地领取，检查负重。
6. **试战与维养**：用剑与布护具参与合适的教学战斗；按既定测试账完成两次维修，最大耐久递减，零耐久停用但物品仍在。
7. **回收与再生产**：确认销毁原件，仅产有限废料；记录材料流出，提交有限采购订单，开始下一轮生产。

同账号生活角色与战斗角色可分工，但旧角色未离场只能重连，不能跳过登出或断线留场切角。玩家不能靠该分工瞬移货物。关键教学奖励避免变成重复建角刷稀有材料的渠道，具体限额与补办方式仍待测。

并行分支保留两派、散人四阶段个人考核，验证三路最高档教学都可单人到达。原型可压缩练习量、复用动作来测试机制，但不得将测试加速误写成正式成长速度。离派不删已学记录，客授不增加第二正式门派身份。

另设“古道受阻”公共事件：成功改善通行或服务条件，失败则进入恢复任务或普通替代路线。不能让失败永久封锁两节点物流、基础服务或全部高阶单人路线；奖励不直接生成违规高级成品。
