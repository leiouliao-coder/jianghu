# 授权代拟完整设计基线 v0.44：剩余细化与实施门槛

## 0. 身份、范围与优先级

用户已授权后续细化由执行方一次完成展示，不再逐条询问。本文件据此给出可执行默认值，身份为**授权代拟设计基线**，不是用户已逐条确认的事实，更不是已开发、已压测或已经平衡。既有用户明确规则优先，本文件补齐叶细则；任何执行模型结果须单独列证据。下文所有时长、费率、阈值和数量均为可版本化测试参数。测试版本调整只作用于新合同、新训练事件或明确迁移过的对象，不能偷偷改写已签承诺。

已确认的基础方向不变：单持久世界、一个人也能长期玩、同号仅一个角色在场、PC键鼠斜俯视3D、服务端裁定；全身实物死亡掉落、公开拾取、尸体30分钟清理；高级装备只由特殊BOSS或高级生活玩家原始生成；无离线练功及离线成长衰减。基础存取、正常与逾期保管本轮0费，不新增市场税，不把有限采购改为无限收购。经济预算和价格演算另附独立总账。

### 0.1 统一补充测试口径

- 尸体30分钟从该次唯一死亡生成时起计，查看、打开和离线不刷新；清空后的尸体外观60秒清理。重连已死亡角色先进入死亡界面，不重新掉落；角色在场租约与尸体实体分开，离场、复活或切角不搬尸。
- 角色总数测试上限6，同号仍只能1个角色在世界在场。配方、技能、任务及关系履历按角色独立；地图发现可以账号共享UI标记，但不赠授业许可、任务完成或物品跨区交付。
- 首轮经济除已预算采购外，个人任务、BOSS和公共事件银钱奖励先设0，授予履历、传承资格或合规材料；公共事件不直接送高级成品装备。未来开启现金奖励必须先有独立、受上限约束的发行预算，不从未定义资金池暗发钱。
- NPC测试基准价每6运行小时检查一次，每次上/下调最多5%，限制在基准价80%—120%。已接合同价不追溯改写；本轮经济附件750断言对应的1小时内固定价演算保持原价格，不重算。

## 1. 第8组：地域市场与物流完整合同

### 1.1 路线、运费与基础可达性

| 项目 | 普通路线 A—B | 自愿风险捷径 A—B |
|---|---|---|
| 设计运输时间 | 10分钟 | 6分钟 |
| 风险 | 普通PVE风险，不允许非自愿PVP；不是无损保险 | 明示可受玩家攻击、夺货及PVE风险 |
| NPC基础承运 | 每10分钟一班，每班20货格；每账号单班最多4格，空余在发车前1分钟释放 | 首轮NPC不运营，玩家自主选择 |
| 自押/玩家承运 | 有合法载具或货包装载后实际移动 | 接受风险提示后实际移动 |
| 服务中断保障 | 公共事件不得永久阻断基础班次；改走已公布普通替代路并顺延受影响合同 | 不保证捷径始终开放，但不可替代必经普通路线 |

测试货格等于实际独立运输容器中的堆叠格，不虚拟合并不同货包；NPC每班20格且整班合计100重量，每账号每班最多4格，预约须同时满足剩余格与剩余重量。自押受角色负重与载具单运输单位100重量双限制，玩家承运同样按真实载具总格/总重检查；不是每个小货包各有100重量，更不能嵌套无限载货。超额必须预约后续班次或实际增加独立载具，不超载出发。NPC班次时间只是模型配置，不是实测到货承诺；合同显示本班实际计划、最迟履约点及可核对状态。

运费测试价表：NPC普通路线 `F=ceil(2+1×货格数+0.02×重量)`；玩家承运风险捷径指导价在同一基础上另加 `0.005×声明价值` 后向上取整，指导价不强制成交价，双方接单前协商并锁定实价。自押不收NPC承运费。货格和重量均用同一次实际装载快照，拆单重新报价，不能重复享受同一次基础服务。上述是本文件新增物流测试参数；经济附件的NPC购料制造演算不含运输服务，不在其流水外暗中追加运费。NPC承运费从起运节点本地银钱收取并计系统回收；玩家运费不是回收，需约定目的节点本地付款，接单前即在那里托管。自押只承担实际所用服务或载具费用，不强行缴纳NPC承运费。起运前展示总价、付款地、风险、期限、责任及是否保赔；不把风险不同、责任不同的货物混成一个不透明价格。

无人在线不暂停已发出的NPC班次；无人在线时也没有角色自动自押。NPC仅在已锁定货物、运力和目的容量后执行基础物流。人少时可能排班等待，但能有限速率持续送达，不能靠无限NPC运力抹掉物流职业价值。货主可以放弃新预约，已发运货物必须完成实体处理。

### 1.2 唯一实物与费用、押金的地点

标准合同含唯一合同ID、货物ID与数量、起终节点、交付条件、路线、运费、最迟到达、迟延规则、估价、责任上限、接管权限、押金位置及各方签署参数版本。实物状态：起点仓内锁定→装载/承运中→目的交付锁定→验收→本地待领；部分货损分拆为可追溯子批次。状态不是复制容器。

现金同样有地点。玩家承运报酬和担保押金均预置于**目的节点**：货主从其目的节点可用银钱冻结运费，承运者从其目的节点可用银钱冻结赔付押金。没有目的节点现金时，可先用普通物流运输实物银钱，不凭合同生成异地余额。NPC起点服务收费直接回收，不需要凭空转给目的NPC。若货主仅在起点有钱且不愿预运，可选起点结算模板，所有现金交付仍在起点待领，界面必须明确“到目的交货、回起点领款”，不得暗中跨节点支付。

普通托运没有默认货值保证，但不免除合同明确的违约责任。担保托运测试声明价值 `V=锁定数量×公开参考单位价`，不接受货主随意报天价；首轮押金为V的100%，只能承接已有足额押金的合同。超高价值、参考价缺失物品首轮不开放系统担保，可以普通托运并明示风险。押金只是冻结，不是发行、回收或第二份货物。押金不足拒绝新单，不从其他节点强扣。

### 1.3 交付、迟延、取消与争议

| 事件 | 代拟默认处理 |
|---|---|
| 完整按时交付 | 系统验货，交付物转货主目的节点待领，运费转承运者约定付款节点待领，押金解冻；货主离线照常结算 |
| 部分交付 | 按子批次数量和锁定参考价值分别验收；基础发车服务费在实际发车后成立，可变运费按验收价值比例结算，未履约部分按合同退回 |
| 超时 | 标记迟延，不认定全损；每完整迟延小时扣应付可变运费5%，最多50%，不自动动用全部货值押金 |
| 控制宽限 | 自押/玩家操控断线给予5分钟等待提示，货物仍受风险；宽限不延长原合同，操作接管必须先授权且实际到场交接 |
| 发运前取消 | 解锁实物、报酬及押金，未发服务不收费；不复制货物或送往别处 |
| 发运后申请取消 | 停止新增路段、前往当前可达合法节点；真实卸载后再决定返运/改约，已完成服务可收费，返程是新运输 |
| 达最迟交付后24小时未完成 | 系统按实际存货、失货和责任结算或局部争议；活货不因超期消失，未能定位的货物标异常锁定调查，不补发副本 |
| 争议 | 当事人72小时内提交；系统先核日志，人工处理目标3工作日，目标不是已达SLA；只冻结争议金额，物理安全处置不停止 |

迟延罚款、损货赔付、运费退款分别列账；同一损失的累计补偿不得超过约定损失上限，迟延服务惩罚另列且有封顶。双方恶意合谋、假抢货触发证据调查，不因正常断线直接判诈骗。超时若由系统故障/维护造成，按影响记录顺延，不让承运者承担平台原因。

货损确认后按责任支付已有押金：合法风险损失是否赔，取决于选定担保条款；普通模板不会自动担保。追回货物仍是原唯一物品，**合法拾取成功转属的规则不可被追偿推翻**。合同只约束签约方，不赋予原货主对合法第三方物品的无限取回权，不远程冻结、召回第三方已取得的原物，也不制造追回副本。只有签约方通过买回、归还、再次合法拾取等方式实际合法重新取得该原物，并实际送入相应本地保管后，才依接单前约定启动退赔核账。标准担保模板要求签约货主实际重新取得已赔原物时退还对应已收赔款；未付赔款可抵扣，已付而应退未退的签约方资产仅按其事先授权的本地保管协议处理，不扩大至无关第三方物品、不远程扣其他节点钱。未实际取回原物只保留事件记录，不虚记追回；争议或违约进入合同责任处理，不能倒改第三方合法所有权。不愿接受此签约方追偿条款的双方不使用该标准担保模板。

## 2. 第9组：任务、社会与持续内容

### 2.1 任务模型和不可卡死规则

任务有个人剧情、可重复事务、授业考核、公共事件、合同五类；合同另用明确法律式状态，不混为“交任务”。个人任务状态为未接/进行/可结算/完成/失败可恢复，保存关键经历而非只记一个全局进度数字。必要进阶不能只靠唯一限时公共事件成功，也不能要求另一名真人在线。

任务物品若为实体，照常随身全掉。补办不是复制：系统先核对原件；已知原件仍存在时可发替代考验，或要求取回。确需补发，旧件须先被标记失效且不能再交任务；失效只改变任务凭证资格，不远程收回可交易原物。替代任务不额外发同一稀有经济奖励。知识、口供和任务进度是非实体记录，不伪装成可掉落物。

公共“古道受阻”测试周期60分钟，参与窗口15分钟，失败影响捷径耗时、特定采购需求及奖励，不关闭基础普通物流。失败后30分钟开放个人清障/侦察恢复事务；无人完成时NPC逐步恢复普通通行，风险捷径仍可保留后果。贡献按有效行为而非最后一击；角色每日奖励次数上限先2次，奖励进入统一发行预算，不能刷事件凭空发币。

### 2.2 四种评价与门派操作

人物关系、势力评价、江湖声望、交易信用各角色独立。前三者测试用−100至100、0至100、−100至100的少量值，另记关键经历；交易信用只记录已履约/迟延/责任货损/争议结果及样本量，不把一次断线直接定为骗子。评分不能合并成万能好人值，系统异常结算不降信用。履历保留时间首轮180天详细、其后摘要留存；真实隐私与法定保留要求实施前另作合规核对。

门派贡献为个人账、不得交易或同号转移；NPC事务、教学帮助和个人考验提供来源，战斗与生活各留可行路径。师父信任取决于指定经历，不直接用捐钱刷满。授业条件检查永久培养悟性，部分当前特性检查有效悟性；临时装备不能帮角色偷学永久内容。门派职位不作为所有秘传前置。

正常离派即时失去门内资源和未获课程资格，已学原则保留；未完成本门委托需取消/交还实物后结清，不远程吞包。转派正式身份必须先结束，测试冷却24运行小时防频繁套利，已学许可不追溯删除。叛师仅用于规则预告过的严重行为，禁止拿玩家临时误触直接永久封禁全江湖。叛师暂停本门后续授业及内部服务，恢复路线为返还未结实物、完成3段个人补偿事务及72运行小时观察；不减永久属性/技能，不承诺任何恶行都恢复原职位。公共基础服务和散人路线保留。

秘籍首轮分“可交易教本”和“个人研习凭证”：教本不消耗，学习需角色独立资格，课目与复制权限由配方表限定；研习凭证成功登记时消耗，提交与学会一次事务。禁止玩家无配方批量复制秘籍。丢书不遗忘已学。图样同理：实体交易不共享知识，学习登记到角色；高级图样有个人考验或特殊BOSS等单人路径，系统不因学过就无限赠送实物。

### 2.3 帮会和据点

角色最多一个帮会，可单人成立。首轮创建只要求完成登记教学和本地小额固定材料，不要求人数。权限拆为领袖、财务、合同、据点和普通成员，按操作逐项授权；默认只有领袖能改权限。帮会财物独立法人式容器，不能自动算成员个人资产；提取、转账、承包需额度和日志，高价值操作设置每日上限，独人帮也可使用但确认提示明确。

领袖30天未上线可触发已指定副手接任；无副手则其他成员发起7天通知期、活跃成员过半确认；单人帮无他人时保持休眠，不强制把资产没收。原领袖回归不自动夺权，可按记录申诉异常接管。解散须清完合同、托管与分配方案，不自动吞财物；争议资产保留节点保管。

据点首轮只争经营分成、可选资源和装饰，战时窗提前24小时公布且只影响该据点。不能占领基础城镇服务、垄断全部正常材料或最高阶单人路线；单人帮可建帮经营，不保证单人能赢所有领地战。无玩家掌门。首版不做强制老死、生育及代际重置。

技能默认按下快速施放，设置提供按住预览松开释放；无合法目标时显示原因，不扣资源。友方、敌方、地面危险同时用轮廓/图形/文本区分，不只靠红绿。遮挡角色的屋顶树冠淡化，重要前摇与控制提示有简化特效选项。收费外观不得改判定轮廓、隐藏前摇或伪装阵营。首轮不因手柄/移动端添加额外主动位。

### 3.2 战斗时点和切换

合法起手时锁本次参数并扣资源、开启冷却；非法目标不扣，起手后落空或被打断不返还，只有招式明确写出的返还才适用。前摇可否移动/转向/打断，生效帧、后摇以及可取消标签逐招配置；预览提示不等于已起手。持械/空手切换测试耗时1秒，期间不能攻击，受控制可中断；同战斗角色共享两套配置的对应槽冷却，取较长剩余时间，不通过切换清空。没有合法武器或武器零耐久时停止依赖它的招式，空手招须按转换规则生效，不自动免费补一记攻击。

眩晕先沿用0.45秒、结束后2秒抗晕测试；定身不自动封攻击，减速下限测试不低于正常速度40%。同类别控制取更强或更长剩余，不相加堆成永冻。免晕期仍可受伤和其他合法控制，但击退不穿墙、不把角色推入不可达地形。针对BOSS不一刀切完全免控，采用控制量表/短效果替代，具体首轮以一只教学BOSS配置验证。

角色死亡取消其未生效动作；已发出的真实飞行物继续至命中/寿命结束，仍可能造成双方同死；已附着持续伤害按原剩余时间运行，但无人在线不因此自动产生新攻击决策。引导型效果需施放者持续有效则死亡/断线不能满足控制时中止，脱手型召唤只执行事先规则，不新增断线自动追杀AI。服务器先按精确生效时刻排序，同一生效时刻用固定事件序：先处理已合法生效的控制，打断当时尚未生效且可打断的动作；再收集该时刻已合法成立的伤害批次并统一扣血，最后统一死亡。时间更早已经成立的伤害不能被较晚控制追溯撤销。已经脱手的弹体不因施放者同批死亡而撤回，因此允许双方同死。固定序号及原因写事件日志，不依网络包先到或客户端画面先后偏袒一方。

PVE15秒/PVP30秒脱战、脱战后180秒离场继续作测试。有效伤害、敌对控制、治疗正在战斗者均更新相关战斗计时；普通读书或无目标空放不延战。PVP优先使用较长规则，持续伤害的每次有效结算更新；已脱离且效果消失才正常计时。安全区只禁止新增攻击，不抹掉已经合法存在的状态；战斗优先，延迟退期间操作/遇袭取消。安全区非战网络断线仍进入重连保护流程，测试30秒后离场；正常主动安全登出仍秒退，两者分开记录。

### 3.3 成长补全

五属性20起、单100/总300、最低10、完整0.1结算沿用测试；减来源按玩家优先级选一个足够0.1的来源，不拼扣。不足只保留一步训练资格，改按钮不立即兑现，须新有效实践。有效性用行为完成、适宜强度、资源/目标真实及冷却条件判断，禁止仅因行为重复就认定作弊。每门武学0—1000独立，不设武学总熟练度预算；生活技能单100/总300独立预算。

生活专业调整采用**主动放弃旧技能点、重新实践学习**，不直接套属性增减按钮：在生活教学NPC可选择旧专业降到明确目标，二次确认后永久扣除所选熟练度、释放生活总预算，不赠予其他专业点；每24运行小时一次，未完成加工/维修委托不得放弃其必要资格。配方知识仍保留，失去技能门槛时不能生产，重新练回无需重新买同一本配方。离线不扣技能，不因改行清空五属性。

有限突破测试：单项可分5次各提高1，上限100→105；总上限可分5次各提高1，上限300→305。两类资格各自记录、只抬上限不送点、不互相自动增加。单项材料由个人长线考验或特定单人可行特殊BOSS提供；总额突破用跨生活/战斗的个人里程碑，每档有替代路线，不能只靠PVP获胜。首轮突破材料不由普通NPC无限售卖；天材地宝明确是**真实实物、使用一次消耗一份、携带时正常死亡掉落**，不偷偷变成免掉落记录。任务资格仅代表使用许可，不等于已经拥有宝物；检查许可、材料身份和角色剩余突破次数后，原子消耗实物并抬高对应上限，重复请求不再消耗或抬升。首轮宝物可当面交易和本地寄售，但使用许可按角色独立获得，不能共享仓库就共享许可。所有五项均能获得对应单项突破资格和真实材料的单人获取路径。

学习条件检查永久培养值，暂时装备不绕过；“当前悟性特性”检查永久值+合法装备/短效修正的有效值，上下限测试0—110。失去装备、掉落或有效值跌破门槛时暂停该特性，不删除武学或熟练度；重新达标在下一合法行为重算，不补发过去伤害。不同属性的装备收益均有限幅，不能无限叠成数值碾压。

### 3.4 生活技能独立训练结算

采矿、冶炼、锻造、纤维采集、纺织、裁缝各按0—100独立熟练度，六项总预算300；不套用武学0—1000或其每次+1公式。有效采集、加工、制造、对应专业维修基本增长量测试为0.1，适宜匹配难度系数1，明显低适宜/重复低难度但仍有效系数0.2；过难且无有效成果也无训练价值系数0，有真实训练价值而未成有效成果系数0.5，须由该工序定义，不能一律失败刷点。正常重复匹配活动不额外惩罚。

技能训练最小有效间隔：采集3秒、冶炼/纺织加工5秒、锻造/裁缝制造10秒、维修10秒；以真实完成工序、材料消耗及实际磨损为准，不能反复空修或取消。每项独立累计小数进度，满0.1才结算完整0.1；单项和总预算均检查，不自动从别项扣除、不拼扣来源。受阻最多保留下一步0.1所需进度，不靠多次无效活动囤点；改行释放预算后仍由新有效实践触发。配方知识是独立资格，不是熟练度，更不是可以兑换技能点的同名货币。属性训练另行判断，一次生活动作可通过自己的条件增加技能，也可能增加对应属性，二者不互相强迫成功。

### 3.6 属性、派生与训练测试公式

这部分是新增可实现测试默认，不是重写旧演算。五项有效属性统一为 `clamp(永久培养值+合法装备/短效修正,0,110)`；永久培养总额仍只累计永久值，临时效果不赠永久预算。基准永久五项各20、熟练度0、不穿护具时采用下表：

| 派生项 | 新测试公式与边界 |
|---|---|
| 气血上限 | `800+10×有效根骨`，基准1000 |
| 内力上限 | `80+有效定力`，基准100 |
| 体力上限 | `80+有效根骨`，基准100 |
| 移动速度 | `4×clamp(1+0.0015×(有效身法−20),0.9,1.15)` 米/秒 |
| 主武学直接伤害 | `招式基数×(1+0.0015×(有效臂力−20))×(1+0.0001×该武学熟练度)`，最终向下取整数 |
| 护具减伤 | 配置表累计后限制0—25%，在直接伤害后结算；特殊伤害例外须逐项显式配置 |
| 定力稳定性 | 抗干扰系数 `clamp(1+0.001×(有效定力−20),0.98,1.09)`，只乘明确标注的运功稳定阈值，不使角色免控 |
| 战内自然恢复 | 气血0、内力1/秒、体力3/秒；每秒服务端结算，不突破上限 |
| 脱战自然恢复 | 气血上限2%/秒、内力上限3%/秒、体力上限5%/秒；安全点可完成免费恢复 |

悟性不参与全局伤害或成长倍率；当前特性仍按其明确门槛与有效悟性判断。样表原先独立场景固定1000/100/100且不自然恢复、直接按基数扣血，保留为历史规则演算，不因本段新增全角色公式擅自重算或声称旧例已用此公式验证。资源降为0不阻止0成本普攻及普通行走。最大资源下降时当前值裁至新上限，不产生伤害事件；上限提高只提高容量，不立即补满。

属性进度使用各属性独立、未归一的训练token：当前永久值低于70，每0.1需100 token；70至不足90需300；90至当前个人上限需600。有效来源活动默认每次合格完成给10 token，同一属性同一来源最短间隔3秒；真实较长工序按完成工序而非每秒发10。跨过区段后按新阈值结算，不把旧低阈值进度倍增。受阻最多存当前下一步所需token，超过的截断；受阻原因消失也不因切按钮自动兑现，仍由新有效实践触发一次完整0.1。一次事件每属性最多结算一步；不强迫一次行为训练所有属性。

武学熟练度测试：0—不足200，每次合格实践+1；200—不足600，+0.5；600—1000，+0.2；上限截断，内功/轻功各检查自己的有效行为。普通攻击每门最短有效间隔2秒，轻功6秒，内功稳定练习每完整10秒窗口评一次；命中/避招/打断须真实有效，不能对空气按间隔机械发点。适宜难度正常收益；明显低于当前能力但仍有真实训练负荷的活动乘0.25，绝对无负荷的无效动作0。重复同一适宜训练不自动降为0，保证砍树、打铁等长期生活仍可成长。具体活动标签、负荷分档和token量入配置表。以上不承诺现实练满小时数，也不允许离线自动累计。

## 4. 第11组：技术、运营和安全

### 4.1 设计架构，不是现成运行系统

选择单地域部署、分区地图进程、中心账号/角色/物品账本的模块化服务方案；首轮客户端平台选Windows 64位、服务端Linux 64位，其他PC操作系统后续依成本与兼容性评估；这是授权代拟平台范围，不冒称用户过去已确定Windows独占。PC客户端可用Unity引擎家族实现风格化3D，服务端选择.NET家族，关系数据库PostgreSQL家族作持久主账，内存缓存只作加速不作唯一资产来源。具体版本实施时锁定兼容矩阵，不宣称最新版。首轮不用微服务泛滥或多地域强一致扩容。

权威范围：位置及速度合法性、技能阶段、命中伤害、资源、成长、掉落拾取、容器权限、交易预算和合同结算全在服务端。客户端预测动作与插值，不决定资产和伤害；地图进程不能凭本地缓存独立生成第二份物品。

每写事务有request_id、角色/账号/物品ID、参数版本、前置版本、提交结果；同请求重放返回原结果，不重复扣/产。同一物品位置变更以条件更新+行锁/事务保证，资金非负，冻结与实余额一致。跨区角色使用所有权令牌和单一激活租约：目标区准备→主账提交交接→旧区停止→新区激活；失败回到已确认所有者，不两边同时作战。同号切角必须等待全世界角色在场租约结束，不能只看客户端退出。

### 4.2 数据恢复、维护与反作弊

测试世界可按公开轮次重置并保存证据，不与正式世界不常规清档混淆。目标备份策略为连续日志归档、每日全备、异机隔离副本；设计目标RPO≤5分钟、RTO≤2小时，只能在恢复演练后对外宣称达标。恢复资产账与事件账须同一致性点；恢复产生重复请求要幂等，不靠简单回滚数据库后继续收新付款。若未来接支付，支付事实独立核账，不让已收现金凭回档消失。

维护提前公告，停止新高风险合同承诺，已有事项记录精确受影响区间。尸体、到货领取、合同、班次按受影响实际时长顺延；未受影响事件不无限补偿。预算按运行小时补充，停机不补无限积压资金；离线世界正常运行时则按预算上限积累。故障赔付需批准的发行记录，不能复制原物补偿。

反作弊分位置/速率/资产/行为证据：超速先校正或隔离异常请求，资产越权拒绝并告警，脚本嫌疑结合日志和复核。重复砍树、锻造本身是合法生活玩法，不能只看高重复就封号。申诉提供事件ID与复核通道；首轮禁止外挂自动操控和同一人通过多账号绕采购限额的组织化刷取，但不把同IP家庭误判同人。多账号识别只用最小必要设备/行为信息，敏感信息不写公开日志；处罚可先冻结涉案额度，不吞无关财产。

先执行0在线、1真人、2账号，然后候选10/30/50并发阶梯；数字是负载输入，不是服务器已支持人数。各档测试移动战斗、同尸抢拾、同单抢购、跨区、断线重连、班次及恢复。设计门槛先用无丢物复制越权、结算幂等100%、服务端关键动作响应p95≤150毫秒（不含公网往返），连续24小时稳定观察；达不到则减负载、修实现，不能改报告说通过。网络延迟/丢包另外注入，客户端总体验独立记录。
