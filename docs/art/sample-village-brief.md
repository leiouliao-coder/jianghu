# 美术样板任务书：河湾镇（A区）＋新手主角

交付对象：肉肉（Codex 云端电脑，使用 Blender）。验收与接入：本机 Claude。
状态：样板阶段，只做 A 区和一个主角。满意后再铺到其他五个区块、怪物和 BOSS。

## 0. 目标

把现在的灰盒（大方块）换成真正的游戏场景和人物，风格对齐仓库里的两张概念图：

- `assets/concept-art/starter-village-wide-v1.png`：新手村远景，白墙灰瓦木构、手绘质感、青绿山水。
- `assets/concept-art/player-novice-v1.png`：初入江湖的玩家，灰蓝粗布短褂、皮带、绑腿、佩剑。

风格要求：精致的风格化 3D 武侠，手绘材质，体块干净；原创中式武侠，不是仙侠，不是写实照片，不是 Q 版。游戏镜头为斜俯视（俯角约 55°，距离 12–60 米），所以屋顶和地面最显眼，细节预算优先放在这两处。

## 1. 交付方式

1. `git clone https://github.com/leiouliao-coder/jianghu.git`，新建分支 `art/sample-village`，推送到这个分支。**不要推送到 main。**
2. 目录约定：
   - `client/assets/art/village/`：建筑、道具的 `.glb`
   - `client/assets/art/characters/`：主角的 `.glb`
   - `client/assets/art/textures/`：地面贴图 `.png`
   - `assets/source/`：所有 `.blend` 源文件和生成用的 Blender Python 脚本（方便以后修改、重新导出）
   - `assets/concept-art/sample/`：你画的设计图（正视、侧视、细节），每张附同名 `-prompt.md` 记录提示词
   - `docs/art/sample-village-manifest.md`：清单（见第 6 节）
3. 推不了 GitHub 的话，请告诉用户，改用上传 Google Drive 并给出文件夹链接。

## 2. 通用技术规格（游戏引擎是 Godot 4.7）

| 项目 | 要求 |
|---|---|
| 格式 | glTF 2.0 二进制 `.glb`，贴图内嵌 |
| 单位 | 1 Blender 单位 = 1 米 |
| 坐标 | Blender 默认 Z 向上；俯视图里 X 向东、Y 向北。导出选 “+Y Up” |
| 原点 | 建筑和道具：占地中心、地面高度；人物：两脚之间、地面高度 |
| 朝向 | 建筑正门、人物正面都朝 Blender 的 −Y（南）。摆放时的旋转由游戏数据决定 |
| 材质 | Principled BSDF：底色、法线、粗糙度/金属度。不要用 Blender 专有节点，导出前全部烘焙成贴图 |
| 贴图 | 单张不超过 2048×2048，PNG |
| 面数 | 每栋建筑 ≤ 20,000 三角面；道具 ≤ 3,000；人物 ≤ 15,000 |
| 渲染 | 游戏使用 Compatibility 渲染器（也要跑在手机上）：不要依赖透射、次表面散射等高级效果；树叶可以用 alpha 裁切 |
| 导出 | 应用所有修改器，清除未使用数据；导出后用 `blender --background` 重新导入一次，确认能打开 |

## 3. 场景资产（尺寸必须精确，游戏服务端按这些占地判定能否通行）

河湾镇是 60×60 米的安全区，中心为出生点 (0,0)。四个方向有路口：西（A–C，宽 8 米）、东（A–B，宽 8 米）、南（A–E，宽 8 米）、北（风险捷径，宽 6 米）。

| 文件 | 内容 | 占地（必须严格遵守） | 说明 |
|---|---|---|---|
| `building_hall.glb` | 客栈兼祠堂：二层木构，白墙灰瓦，飞檐，木柱，门匾位置留空 | **14 × 14 米**，墙体不超出 | 高约 9 米；屋檐可以外挑 1 米以内 |
| `building_forge.glb` | 铁匠铺：一层工坊加半开敞棚，铁砧、炉灶（炉火用自发光材质）、堆料 | **14 × 14 米** | 高约 6 米；工具和堆料都放在占地内 |
| `tree_old.glb` | 村中古树（大榕树或古槐） | 树干半径 ≤ 1.5 米，树冠直径约 12 米 | 只有树干阻挡通行，树冠不挡 |
| `fence_wood_4m.glb` | 木围栏一段 | 长 4 米 × 宽 0.3 米，高 1.2 米 | 用来沿区块边缘围合，路口要留出缺口 |
| `props_set.glb` | 小道具：木箱、木桶、灯笼杆、水井、摊位桌，各做成单独的对象（对象名清晰） | 每件 ≤ 2 × 2 米 | 只做装饰，游戏会摆在不挡路的位置 |

地面贴图（可无缝平铺，2048×2048，每张附法线贴图）：

| 文件 | 用途 |
|---|---|
| `ground_stone_paving.png` | 镇内石板地（安全区） |
| `ground_dirt_road.png` | 出镇土路 |
| `ground_grass.png` | 野外草地 |

## 4. 人物资产：`player_novice.glb`

- 外形照 `player-novice-v1.png`：身高约 1.75 米，高马尾，灰蓝粗布短褂、米色内衫、皮腰带和小布袋、深灰长裤、绑腿、布靴，腰间佩剑（剑做成独立对象，以后会有空手和持剑两种状态）。
- 人形骨架，带蒙皮权重，T 姿态或 A 姿态绑定。
- 动作做成 glTF 动画轨，**名字必须完全一致**：

| 动作名 | 时长 | 要求 |
|---|---|---|
| `idle` | 循环，约 2 秒 | 站立呼吸 |
| `walk` | 循环 | 步幅对应每秒 4 米的移动速度（游戏的移动速度），脚不能打滑 |
| `attack_basic` | 0.70 秒 | 剑的普攻“点锋”：0.25 秒时剑尖命中，之后 0.45 秒收招 |
| `hit` | 约 0.3 秒 | 受击后仰 |
| `death` | 约 1.0 秒 | 倒地，最后一帧保持躺地 |

动作时长要和这里一致，因为游戏的出招判定是按这些时间点精确计算的。

## 7. 验收（由本机 Claude 执行）

1. 每个 `.glb` 能被 Godot 4.7 导入，没有报错；尺寸、原点和朝向符合第 2 节。
2. 建筑占地与服务端地图一致：角色走到墙边会停下，不会穿墙，也不会在空地上被看不见的墙挡住。
3. 主角五个动作都能播放，走路时脚不打滑，`attack_basic` 的命中帧落在 0.25 秒。
4. 用 1280×800 窗口实机截图：镇内全景、主角近景、走路中、出招中，交给用户确认。
